# Código de conducta

Esperamos que todas las personas que participan en este proyecto mantengan un
entorno amable, respetuoso y constructivo.

No se toleran acoso, discriminación, ataques personales, publicación de datos
privados, lenguaje sexual no deseado ni conductas que impidan la colaboración.
Las críticas deben centrarse en el código, las decisiones técnicas y el impacto
para las personas usuarias.

Si observas un comportamiento problemático, repórtalo de forma privada a las
personas mantenedoras del repositorio. Los reportes se tratarán con discreción
y se revisarán de buena fe.
